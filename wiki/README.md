# Project Wiki

This directory is the repository's consolidated knowledge control plane and single source of truth for product intent, compiled domain knowledge, architecture decisions, delivery evidence, lifecycle guidance, governance, and immutable source intake.

Start at the [Wiki Index](index.md). Follow [SCHEMA.md](SCHEMA.md) when adding or compiling knowledge, register immutable evidence in [raw/index.md](raw/index.md), and append durable knowledge operations to [log.md](log.md).

Deployable applications belong in [`apps/`](../apps/), shared code belongs in [`packages/`](../packages/), and executable agentic workflow guides remain in [`workflows/`](../workflows/).
