AI DEVELOPMENT WORKSPACE PLATFORM

Vibe-Code Final Production Architecture

Hong Kong active multi-AZ platform, warm-passive DR, explicit scaling and user-data placement
FINAL TARGET · HK DATA RESIDENCY ASSUMPTION

User/account and platform metadata

HK PostgreSQL private data zone. Users, teams, sessions, projects, job/outbox state, approvals, policy, audit, budget and cost rollups. Primary + standby, PITR and DR-log copy.

Source and workspace data

HK Git + per-workspace PVC. Git commit is source truth; PVC is working filesystem and single-active. Snapshots go to HK object storage; local-path is never the only copy.

Artifacts, evidence and telemetry

HK object/registry/observability stores. Images, packages, snapshots, SBOM, evaluation evidence, logs and traces use explicit encryption, retention, access and deletion policy.

Secrets and AI data boundary

HK Vault/KMS holds references and master keys. Workspaces receive scoped virtual keys only. External model residency/retention is a policy gate; HK-only use requires an HK/private endpoint.
