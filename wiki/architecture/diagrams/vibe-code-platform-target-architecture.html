AI Development Workspace Platform

Vibe-Code Platform Target Architecture

Freedom-first POC creation, isolated workspaces, traceable AI coding and governed IT handover
TARGET ENVELOPE · STAGED DELIVERY

Stage 0–1 · Prove the core journey

Login → projects → isolated Coder workspace → code-server/Cline → authenticated preview → persistent source/data. Keep RabbitMQ, mobile and detached preview out.

Stage 2–3 · Govern and harden

Immutable templates, app packages, handover evidence, scanning, monitoring, backup/restore and measured capacity for 30–50 concurrent users.

Stage 4–5 · Async and mobile

Add durable task truth, outbox + RabbitMQ, isolated agent runners, approvals, event replay, notifications and a task-first mobile PWA.

Hard boundary

The platform is production-grade; generated applications remain POCs. The only exit is a reviewed IT handover into a separate enterprise SDLC.
