# Architecture Decision Records

Store accepted and proposed numbered ADRs in this directory, for example `ADR-0001-use-relational-storage.md`. Create each record from [`../templates/ADR-0000-template.md`](../templates/ADR-0000-template.md).

Do not silently rewrite accepted decisions. Supersede them with a newer ADR and update the current architecture under [`../baseline/`](../baseline/).
